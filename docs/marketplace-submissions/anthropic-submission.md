## Verification to attach

1. Run `claude plugin validate .` with the current Claude Code release.
2. Add `kolabse/skills` as a marketplace in a clean user profile.
3. Install `kolabse-skills@kolabse` and start a new session.
4. Exercise repository synchronization, review, and project digest workflows.
5. Record the Claude Code version, OS, commit SHA, validation result, and
   sanitized observations in the submission.

The submission form performs automated validation and safety screening. Form
submission and any publisher attestations remain explicit maintainer actions.
