이 문서는 한국어 번역입니다. 내용이 다를 경우 [영어 원문](../../../PRIVACY.md)이 기준입니다.

시행일: 2026-08-24

`kolabse-skills`는 에이전트 워크플로의 오픈 소스 모음입니다. 이 모음 자체는
호스팅 서비스를 운영하거나 사용자 계정을 만들지 않으며, 분석 데이터를 수집하거나
kolabse에 원격 측정 데이터를 전송하지 않습니다.

## 처리하는 정보

스킬은 지원되는 코딩 에이전트에 사용자가 작업 범위에 포함한 파일, Git 저장소,
프로젝트 설정 또는 기타 리소스를 조사하거나 수정하도록 지시할 수 있습니다.
처리는 사용자의 에이전트 환경에서 이루어지며, 해당 에이전트와 설정된 모델
제공업체의 개인정보 관련 약관을 따릅니다.

일부 스킬은 Google Drive, Telegram, Git 호스팅 제공업체, Yandex Cloud를
비롯한 제삼자 서비스를 사용할 수 있습니다. 이는 사용자가 해당 워크플로를 호출하고
필요한 설정을 제공하거나 승인한 경우에만 이루어집니다. 해당 서비스는 자체
개인정보 처리방침에 따라 정보를 처리합니다.

## 자격 증명과 비공개 데이터

이 모음은 자격 증명을 저장소 외부에 보관하고, 로그, 릴리스 산출물 또는 동기화된
프로젝트 메타데이터에 비밀 정보가 포함되지 않도록 설계되었습니다. 요청된 접근
권한을 검토하고 에이전트가 처리하거나 설정된 제삼자에게 보낼 수 있는 프로젝트
정보를 선택할 책임은 사용자에게 있습니다.

## 보관 및 삭제

kolabse는 스킬이 로컬에서 처리하는 데이터를 받거나 보관하지 않습니다.
로컬에서 생성한 설정, 증거 자료, 로그 또는 동기화 기록은 사용자가 관리하며,
해당 프로젝트, 에이전트 또는 제삼자 서비스에서 삭제할 수 있습니다.

## 변경 및 문의

이 방침의 중요한 변경 사항은 저장소 이력에 기록됩니다. 개인정보 관련 문의는
자격 증명이나 비공개 프로젝트 데이터를 포함하지 않고
<https://github.com/kolabse/skills/issues>에 이슈를 등록하세요.
