## 사용자의 책임

스킬은 에이전트에 지침을 제공하며 사용자의 검토나 승인을 대신하지 않습니다.
사용자는 적절한 워크플로 선택, 제안된 작업 검토, 자격 증명 보호, 백업 유지,
프로젝트와 고용주 및 제삼자 서비스의 정책 준수에 책임을 집니다.

저장소, 인프라, 문서 또는 외부 서비스를 변경할 수 있는 워크플로는 에이전트 호스트의
권한 체계와 스킬에 명시된 안전 경계를 계속 따라야 합니다. 사용자는 권한 없이
시스템이나 데이터에 접근하기 위해 이 모음을 사용해서는 안 됩니다.

## 제삼자 서비스

Git 호스팅, Google Drive, Telegram, Yandex Cloud 같은 선택적 연동은 독립된
제삼자가 제공합니다. 해당 서비스의 가용성과 이용에는 각 서비스의 약관이 적용됩니다.
kolabse는 이러한 서비스를 통제하지 않습니다.

## 보증 없음

이 모음은 어떠한 보증이나 보장 없이 “있는 그대로” 제공됩니다.
법률이 허용하는 범위에서 유지관리자는 이 모음의 이용으로 발생한 손실에
책임을 지지 않습니다.
