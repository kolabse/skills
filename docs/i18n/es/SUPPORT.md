# Soporte

[English](../../../SUPPORT.md) | [Русский](../ru/SUPPORT.md) | Español | [Français](../fr/SUPPORT.md) | [Deutsch](../de/SUPPORT.md)

Utilice los siguientes canales públicos para `kolabse-skills`:

- problemas de instalación, compatibilidad o flujo de trabajo:
  <https://github.com/kolabse/skills/issues/new/choose>;
- propuestas de funciones y habilidades:
  <https://github.com/kolabse/skills/issues>;
- informes de seguridad que no deban ser públicos:
  <https://github.com/kolabse/skills/security/advisories/new>.

Incluya la versión del plugin, el agente y su versión, el sistema operativo,
el método de instalación, el comando o prompt exacto y la salida de error
depurada. Nunca incluya tokens de acceso, credenciales, contenido de
repositorios privados ni contexto del proyecto sin depurar.

El soporte lo mantiene la comunidad y no tiene un plazo de respuesta garantizado.
