Esta é uma tradução para português do Brasil. Em caso de divergência, a [versão em inglês](../../../SUPPORT.md) é a referência oficial.

Use os seguintes canais públicos para `kolabse-skills`:

- problemas de instalação, compatibilidade ou fluxo de trabalho:
  <https://github.com/kolabse/skills/issues/new/choose>;
- propostas de funcionalidades e skills:
  <https://github.com/kolabse/skills/issues>;
- relatos de segurança que não devem ser públicos:
  <https://github.com/kolabse/skills/security/advisories/new>.

Inclua a versão do plugin, o agente e sua versão, o sistema operacional,
o método de instalação, o comando ou prompt exato e a saída de erro sem dados sensíveis.
Nunca inclua tokens de acesso, credenciais, conteúdo de repositórios privados ou
contexto de projeto que não tenha sido sanitizado.

O suporte é mantido pela comunidade e não tem prazo de resposta garantido.
