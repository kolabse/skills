# Support

English | [Русский](docs/i18n/ru/SUPPORT.md)

Use the following public channels for `kolabse-skills`:

- installation, compatibility, or workflow problems:
  <https://github.com/kolabse/skills/issues/new/choose>;
- feature and skill proposals:
  <https://github.com/kolabse/skills/issues>;
- security reports that should not be public:
  <https://github.com/kolabse/skills/security/advisories/new>.

Include the plugin version, agent and agent version, operating system,
installation method, exact command or prompt, and sanitized error output.
Never include access tokens, credentials, private repository contents, or
unsanitized project context.

Support is community-maintained and has no guaranteed response time.
